# meeting-notes-bot

A Claude Code agent migrated to Trinity as-is. Used in session 2 of the Agent-Native Agency
workshop as the pre-built result of the bring-your-own path (`/agent-dev:agent-fleet-analysis` →
`/agent-dev:agent-fleet-migrate`). Create it from `github:Abilityai/keymaker-meeting-notes-bot`,
tag it `keymaker`, and allow Keymaker Delivery to call it.

`inbox/` holds a sample transcript; `/summarize` writes `notes/<date>-<client>.md`. Apache 2.0.
